# App at a Glance

Find your way around NFS Mobile: the navigation bar, the menu, the shortcuts and the statuses.

## Overview

This page is a map of the app. It shows where each main page is, what the icons open, and what the statuses mean, with a link to the full topic for each one.

## The navigation bar

The navigation bar is at the bottom of the screen. It lets you move between the main pages.

| Icon | Page | What you can do |
| ---- | ---- | --------------- |
| Three horizontal lines | [Menu](menu/README.md) | Change your avatar, see your coworkers, declare an unavailability, set your working hours, read the version note and log out. |
| Gauge | [Dashboard](main-actions/main-actions.md) | See your day at a glance, search for an intervention and list the interventions in progress. |
| Calendar | [Calendar](main-actions/calendar.md) | See your interventions by day, open an intervention and view them on a map. |
| Two people | [Contacts](customer-directory/README.md) | Find customer sites, read their details and act on them from the field. |
| Gear | [Settings](main-actions/settings.md) | Clear the cache, send your logs, choose the measurement unit and read the version of the app. |

## The shortcuts of an intervention

When you open an intervention, a row of shortcuts is displayed at the top of the page. A number on a shortcut shows how many items it contains.

| Shortcut | What it opens |
| -------- | ------------- |
| **Docs** | The files linked to the intervention. See [View the Documents of an Intervention](intervention/documents.md). |
| **Tasks** | The tasks to complete. See [Scan a Task Code](intervention/scan-a-task-code.md). |
| **Photos** | The photos of the intervention. See [Add Photos and Remarks](intervention/photos-and-remarks.md). |
| **Items** | The items that you use. See [Add Items to an Intervention](intervention/add-items-to-an-intervention.md). |
| **Remarks** | The remarks. It is displayed once the intervention is started. See [Add Photos and Remarks](intervention/photos-and-remarks.md#write-remarks). |
| **Reports** | The reports to fill in. See [Fill in the Report](intervention/report.md). |

## The statuses of an intervention

The status is displayed on the **Intervention** page.

| Status | Meaning |
| ------ | ------- |
| **Waiting** | The intervention is planned and waits for your answer. |
| **Accepted** | You accepted it. It is ready to start. |
| **In progress** | You started it. A timer shows its duration. |
| **Completed** | You finished it. |
| **Abandoned** | You declined it. It can be started again if it is sent back to the app. |

The calendar **Legend** lists all the statuses, and the colors of the markers on the map follow them. See [Calendar](main-actions/calendar.md#legend) and [Calendar Map Marker Colors](main-actions/calendar-map-marker-colors.md).

## Where to find a setting

| I want to... | Go to |
| ------------ | ----- |
| Clear the cache or send my logs | [Settings](main-actions/settings.md) |
| Switch between kilometers and miles | [Change the Measurement Unit](main-actions/change-the-measurement-unit.md) |
| Switch on the privacy mode | [Privacy Mode](menu/coworkers/privacy-mode.md) |
| Change my picture | [Change My Avatar](menu/change-my-avatar.md) |
| Set my working days | [Working Hours](menu/working-hours/README.md) |
| Reload my interventions | [Refresh Your Data](main-actions/refresh-your-data.md) |

{% hint style="info" %}
**Screens can differ**: The icons, the names and the options depend on the version of your app and on the configuration of your company.
{% endhint %}
