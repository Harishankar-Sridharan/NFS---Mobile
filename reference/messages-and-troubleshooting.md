# Messages and Troubleshooting

## Overview

The app displays messages when a step is blocked, when it is working, and when there is no network. This page lists the messages that this guide describes, with the reason and the action, and a link to the topic that explains the step.

## Before you begin

* Read the message in full. Some messages tell you what is missing, for example a number of photos or the list of fields.

## Messages that block a step

| Message | What it means | What to do |
| ------- | ------------- | ---------- |
| **Please fill mandatory report fields to proceed** | A mandatory report, or a mandatory field of a report, is not completed. | Complete the reports that are marked as mandatory. See [Complete the Mandatory Survey Reports](../intervention/mandatory-survey-reports.md) and [Fill in the Report](../intervention/report.md). |
| **Minimum photo requirement not achieved. Please provide 1 more photo(s) to proceed.** | Your company requires a minimum number of photos, and you took fewer. The message gives the number of missing photos. | Take the missing photos, then finish again. See [Take the Required Photos](../intervention/required-photos.md). |
| **Items – Please fill in all required fields for the items used** | A mandatory field of an item that you used is empty. | Open the item and fill in its mandatory fields. See [Mandatory Fields and Drop-Down Lists on Items](../intervention/mandatory-and-list-item-fields.md). |
| **Items – Please fill serial number for:** | The serial number of an item that you used is mandatory and is not recorded. The message lists the items. | Scan or type the serial number of each listed item. See [Scan the Mandatory Serial Numbers](../intervention/mandatory-serial-number.md). |
| **You must have the intervention signed** | The signature is mandatory for this intervention. | Tap **Ok**, then sign. See [Sign an Intervention](../intervention/sign-an-intervention/README.md). |
| **Mandatory information required** | The secure signature needs details of the contact or of the technician that are missing. The message lists them. | Fill in the missing fields. See [Fill In the Required Fields for Electronic Signature](../intervention/sign-an-intervention/required-fields-for-electronic-signature.md). |
| **Unable to retrieve the electronic signature** | An older version of the app displayed this message when the details for the secure signature were missing. | Fill in the details of the contact and of the technician. See [Fill In the Required Fields for Electronic Signature](../intervention/sign-an-intervention/required-fields-for-electronic-signature.md). |
| **Warning** with **Do you wish to continue?** | You already have interventions in progress, and you start or restart another one. The message lists them. | Tap **Continue** to start this one too, or **Cancel**. See [Start an Intervention](../intervention/start-an-intervention.md). |
| **Impossible to swap selected interventions** | The back office says that the two interventions cannot be swapped. | Choose other interventions. See [Swap Two Interventions](../main-actions/swap-interventions.md). |
| **Impossible to swap** with **Force** and **Ignore** | The swap breaks a constraint. The page lists the reasons. | Read the reasons, then tap **Force** or **Ignore**. See [Swap Two Interventions](../main-actions/swap-interventions.md). |
| **Why are you manually scanning this optic code ?** | A scan task is completed by hand. | Choose a reason. See [Keep the Task Comment When You Scan by Hand](../intervention/task-comment-and-manual-scan.md). |

## Messages about a file or a photo

| Message | What it means | What to do |
| ------- | ------------- | ---------- |
| **Insufficient quality** | The photo is too blurry, or does not meet the criteria. | Take the photo again. See [Add Photos and Remarks](../intervention/photos-and-remarks.md). |
| **Review Images** | One or more images are too blurry. The page asks you to select the images to keep or remove. | Tap the bin to remove them, or the check mark to keep them. See [Add Files and Signatures to a Survey Report](../intervention/add-files-to-a-survey-report.md). |
| **File exceeds maximum size** | The file is larger than the size that is allowed. | Choose a smaller file. See [Add Photos to a Site](../customer-directory/add-photos-to-a-site.md) and [Change My Avatar](../menu/change-my-avatar.md). |

## Messages about a code

| Message | What it means | What to do |
| ------- | ------------- | ---------- |
| **No intervention found for the scanned code** | No intervention of your agenda has this code. | Check the code, then scan it again. See [Open an Intervention with a Scan](../main-actions/open-an-intervention-with-a-scan.md). |
| **Scan code is empty or contains only spaces** | The code that you scanned or typed is empty. | Scan or type the code again. See [Open an Intervention with a Scan](../main-actions/open-an-intervention-with-a-scan.md). |
| **Unknown item** | The scanned code does not match the pattern that your company set for serial numbers. | Scan the right code. See [Accept Only Valid Scan Codes](../intervention/valid-scan-codes.md). |
## Messages about the network

| Message | What it means | What to do |
| ------- | ------------- | ---------- |
| **You are offline. No interaction will be lost** | Your device has no network. The app keeps your work. | Keep working. The data is sent when the network is back. See [Fill In Survey Forms Offline](../intervention/fill-in-forms-offline.md). |
| **Awaiting network connection. Data synchronization will occur on the next available connection.** | You tapped the AB button without a network. The app waits to correct the text. | Keep working. The text is corrected when the network is back. See [Correct Your Text with AI](../intervention/correct-your-text-with-ai.md). |
| **Waiting for a network connection** | The app kept your action and waits for the network. | Connect your device, then synchronize your data. See [Refresh Your Data](../main-actions/refresh-your-data.md). |
| **Request failed** | The app could not send the file, or a refresh found nothing new. | Try again later. See [Send Your Location Logs](../main-actions/send-location-logs.md) and [Restart an Abandoned Intervention](../intervention/restart-an-abandoned-intervention.md). |
| **Intervention swap in progress – Please wait** | The app is waiting for the answer of the back office about a swap. | Wait. See [Swap Two Interventions](../main-actions/swap-interventions.md). |
| **Sending data in progress – Please wait** | The app is sending your data. | Wait. Do not close the app. See [Finish an Intervention](../intervention/finish-an-intervention.md). |

## Messages about a search

| Message | What it means | What to do |
| ------- | ------------- | ---------- |
| **No results found** | No report matches what you typed. | Type another part of the name. See [Add and Delete a Report During an Intervention](../intervention/add-a-report.md). |

## When a screen does not look as it should

1. Refresh your data. See [Refresh Your Data](../main-actions/refresh-your-data.md).
2. If your administrator changed a setting, log out and log in again. The app loads the new settings at login.
3. If the problem stays, note the version of the app, shown in **Settings** under **About Application**, and send your logs. See [Settings](../main-actions/settings.md).
4. Give the version and a short description of the steps to your administrator or to the support team.

## Tips

{% hint style="info" %}
**Settings that block a step are set by your company**: A mandatory report, a minimum number of photos or a mandatory signature is not an error of the app. Your administrator sets them. See [Mobile Configuration](../configuration/README.md).
{% endhint %}
