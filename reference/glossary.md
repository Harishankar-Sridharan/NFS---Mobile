# Glossary

Find the meaning of the words that the app and this guide use.

## Overview

The words are in alphabetical order. Each definition has a link to the topic that explains it in detail.

## Terms

| Term | Meaning |
| ---- | ------- |
| **Abandoned** | The status of an intervention that you declined to carry out. It can be started again if the back office sends it back to the app. See [Abandon an Intervention](../intervention/abandon-an-intervention.md) and [Restart an Abandoned Intervention](../intervention/restart-an-abandoned-intervention.md). |
| **Accepted** | The status of an intervention that you confirmed. It is ready to start. See [Calendar](../main-actions/calendar.md#accept-an-intervention). |
| **Agenda** | Your schedule of interventions, rests, lunch breaks and unavailabilities. It is displayed on the **Calendar** page. See [Calendar](../main-actions/calendar.md). |
| **Avatar** | The round picture of your profile, in the **Menu** and on the dashboard. See [Change My Avatar](../menu/change-my-avatar.md). |
| **Back office** | The web application of NFS, where planners work and where administrators set up the app. See [Mobile Configuration](../configuration/README.md). |
| **Cluster** | A numbered circle on a map that groups the markers that are close together. See [Clustered Markers on the Maps](../main-actions/map-clustering.md). |
| **Completed** | The status of an intervention that you finished. See [Finish an Intervention](../intervention/finish-an-intervention.md). |
| **Contact** | A person of a customer. The main contact is the one that the app calls first. See [Quick Actions on an Intervention](../main-actions/long-press-an-intervention.md). |
| **Custom setting** | A parameter of the back office that changes how the app works, for example the number of required photos. See [Application Settings for NFS Mobile](../configuration/application-settings.md). |
| **Dashboard** | The home page of the app, with your day at a glance. See [Dashboard](../main-actions/main-actions.md). |
| **Grouped intervention** | An intervention that belongs to a group of interventions of the same customer on the same day. See [Grouped Interventions](../main-actions/grouped-interventions.md). |
| **Hotel night** | A night away from home that your planner assigns to a hotel. See [Hotel Nights in the Calendar](../main-actions/calendar-hotel-nights.md). |
| **In progress** | The status of an intervention that you started. A timer shows its duration. See [Start an Intervention](../intervention/start-an-intervention.md). |
| **Intervention** | A visit planned for you at a customer site. NFS calls it an appointment. See [Intervention](../intervention/README.md). |
| **Item** | A product that you use or sell during an intervention. Also called an article. See [Add Items to an Intervention](../intervention/add-items-to-an-intervention.md). |
| **Mandatory report** | A survey report that you must complete before you can finish the intervention. See [Complete the Mandatory Survey Reports](../intervention/mandatory-survey-reports.md). |
| **Measurement unit** | The unit of the distances in the app, kilometers or miles. See [Change the Measurement Unit](../main-actions/change-the-measurement-unit.md). |
| **NFS** | Nomadia Field Service. The application where interventions are planned, and the system that the app sends its data to. |
| **NFS Mobile** | The mobile app of the field operators. See [Introduction](../introduction.md). |
| **Offline** | Without a network. The app keeps your work and sends it when the network is back. See [Fill In Survey Forms Offline](../intervention/fill-in-forms-offline.md). |
| **Privacy mode** | A switch that stops the sharing of your position and hides the positions of your coworkers. See [Privacy Mode](../menu/coworkers/privacy-mode.md). |
| **Rest** | A period of your agenda when you do not work. See [Calendar](../main-actions/calendar.md#day-agenda). |
| **Serial number** | The code that identifies an item for one intervention. See [Scan or Enter a Serial Number](../intervention/scan-a-serial-number.md). |
| **Signature** | The proof that the customer accepted the intervention. You sign by hand or securely. See [Sign an Intervention](../intervention/sign-an-intervention/README.md). |
| **Site** | A location of a customer. See [Customer Directory](../customer-directory/README.md). |
| **Survey report** | A report made of a form with several questions. See [Fill In Survey Forms Offline](../intervention/fill-in-forms-offline.md). |
| **Synchronization** | The exchange of data between the app and NFS. See [Refresh Your Data](../main-actions/refresh-your-data.md). |
| **Task** | A step that you complete during an intervention, before you accept it, before you start it or during it. See [Scan a Task Code](../intervention/scan-a-task-code.md). |
| **Unavailability** | A period when you are not available, for example a leave or a meeting. See [Unavailabilities](../menu/unavailabilities/README.md). |
| **Waiting** | The status of a new intervention that is waiting for your answer. See [Intervention](../intervention/README.md#intervention-statuses). |
| **Working hours** | The days and the hours when you are available. See [Working Hours](../menu/working-hours/README.md). |
