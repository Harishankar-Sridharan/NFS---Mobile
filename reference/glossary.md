# Glossary

Find the meaning of the words that the app and this guide use.

## Overview

The words are in alphabetical order. Each definition has a link to the topic that explains it in detail, and to the administrator topic when your company can set it up.

## Terms

| Term | Meaning |
| ---- | ------- |
| **Abandoned** | The status of an intervention that you declined to carry out. It can be started again if the back office sends it back to the app. See [Abandon an Intervention](../intervention/abandon-an-intervention.md) and [Restart an Abandoned Intervention](../intervention/restart-an-abandoned-intervention.md). Administrators: see [Abandoned Missions Setup](../configuration/abandoned-missions-setup.md). |
| **Accepted** | The status of an intervention that you confirmed. It is ready to start. See [Calendar](../main-actions/calendar.md#accept-an-intervention). |
| **Access an intervention** | A calendar action that opens the camera. When you scan the code of an intervention, the app opens it. See [Open an Intervention with a Scan](../main-actions/open-an-intervention-with-a-scan.md). Administrators: see [Intervention Scan Code Setup](../configuration/intervention-scan-code-setup.md). |
| **Added report** | A report that you added yourself during an intervention. You can delete it until it is submitted. See [Add and Delete a Report During an Intervention](../intervention/add-a-report.md). |
| **Agenda** | Your schedule of interventions, rests, lunch breaks and unavailabilities. It is displayed on the **Calendar** page. See [Calendar](../main-actions/calendar.md). |
| **Avatar** | The round picture of your profile, in the **Menu** and on the dashboard. See [Change My Avatar](../menu/change-my-avatar.md). |
| **Back office** | The web application of NFS, where planners work and where administrators set up the app. See [Mobile Configuration](../configuration/README.md). |
| **Cancel** | To return an intervention that you started to the accepted state. See [Cancel an Intervention](../intervention/cancel-an-intervention.md). |
| **Cluster** | A numbered circle on a map that groups the markers that are close together. See [Clustered Markers on the Maps](../main-actions/map-clustering.md). |
| **Completed** | The status of an intervention that you finished. See [Finish an Intervention](../intervention/finish-an-intervention.md). |
| **Contact** | A person of a customer. The main contact is the one that the app calls first. See [Quick Actions on an Intervention](../main-actions/long-press-an-intervention.md). |
| **Coworker** | A colleague whose position you can see on a map. See [View Your Coworkers](../menu/coworkers/view-your-coworkers.md). |
| **Create an intervention** | To create a new intervention on the spot, from the **Intervention** page. See [Create an Intervention](../intervention/create-an-intervention/README.md) and [Choose the Site](../intervention/create-an-intervention/choose-the-site.md). |
| **Custom setting** | A parameter of the back office that changes how the app works, for example the number of required photos. See [Application Settings for NFS Mobile](../configuration/application-settings.md). |
| **Dashboard** | The home page of the app, with your day at a glance. See [Dashboard](../main-actions/main-actions.md). |
| **Declare** | To ask for an unavailability, for a day to come or for a day in the past. See [Declare an Unavailability](../menu/unavailabilities/declare-an-unavailability.md). |
| **Decline to sign** | To refuse to sign and explain why. See [Decline to Sign](../intervention/sign-an-intervention/decline-to-sign.md). |
| **Directions** | The route to a site, opened in your navigation app. See [Get Directions to a Site](../customer-directory/get-directions-to-a-site.md). |
| **Documents of an intervention** | The files and the reports that are linked to an intervention. See [View the Documents of an Intervention](../intervention/documents.md). |
| **Drop-down list** | A field that offers a list of values to choose from. See [Mandatory Fields and Drop-Down Lists on Items](../intervention/mandatory-and-list-item-fields.md). |
| **Extra fields** | Additional fields that your company adds to an item, such as a link, a checkbox, a number or a date. See [View and Edit the Extra Fields of an Item](../intervention/edit-extra-item-fields.md). Administrators: see [Extra Item Fields Setup](../configuration/extra-item-fields-setup.md). |
| **Group concerned** | The group of unavailability types that you pick first. The list of types then shows only the types of that group. See [Choose the Unavailability Type by Group](../menu/unavailabilities/choose-the-unavailability-type-by-group.md). Administrators: see [Unavailability Groups Setup](../configuration/unavailability-groups-setup.md). |
| **Grouped intervention** | An intervention that belongs to a group of interventions of the same customer on the same day. See [Grouped Interventions](../main-actions/grouped-interventions.md). |
| **Hotel night** | A night away from home that your planner assigns to a hotel. See [Hotel Nights in the Calendar](../main-actions/calendar-hotel-nights.md). Administrators: see [Hotel Nights Setup](../configuration/hotel-nights-setup.md). |
| **In progress** | The status of an intervention that you started. A timer shows its duration. See [Start an Intervention](../intervention/start-an-intervention.md). |
| **Intervene now** | To create an intervention and start it immediately. See [Intervene Now](../intervention/create-an-intervention/intervene-now.md). |
| **Intervention** | A visit planned for you at a customer site. NFS calls it an appointment. See [Intervention](../intervention/README.md). |
| **Intervention for a site** | A new intervention that you create from the page of a site. See [Create an Intervention for a Site](../customer-directory/create-an-intervention-for-a-site.md). |
| **Item** | A product that you use or sell during an intervention. Also called an article. See [Add Items to an Intervention](../intervention/add-items-to-an-intervention.md). |
| **Item details** | The page of an item with its stock, its references, its unit price and its description. Also called the product sheet. See [View the Details of an Item](../intervention/view-item-details.md). |
| **Location log** | The file that records how your position was tracked. You can send it to the back office. See [Send Your Location Logs](../main-actions/send-location-logs.md). Administrators: see [Location Logs Setup](../configuration/location-logs-setup.md). |
| **Login** | To sign in to the app with your credentials, in order to open your dashboard. See [Login](../app-launch/app-launch.md). |
| **Mandatory field** | A field that you must fill in before you can finish. A red asterisk (*) marks it. See [Mandatory Fields and Drop-Down Lists on Items](../intervention/mandatory-and-list-item-fields.md) and [Fill in the Report](../intervention/report.md). |
| **Mandatory report** | A survey report that you must complete before you can finish the intervention. See [Complete the Mandatory Survey Reports](../intervention/mandatory-survey-reports.md). Administrators: see [Mandatory Reports Setup](../configuration/mandatory-reports-setup.md). |
| **Marker color** | The color of an intervention marker on the calendar map. It shows the status of the intervention. See [Calendar Map Marker Colors](../main-actions/calendar-map-marker-colors.md). |
| **Measurement unit** | The unit of the distances in the app, kilometers or miles. See [Change the Measurement Unit](../main-actions/change-the-measurement-unit.md). Administrators: see [Measurement Unit Setup](../configuration/measurement-unit-setup.md). |
| **Menu** | The page that groups your avatar, your coworkers, your unavailabilities, your working hours, the version note and the log out. See [Menu](../menu/README.md). |
| **NFS** | Nomadia Field Service. The application where interventions are planned, and the system that the app sends its data to. |
| **NFS Mobile** | The mobile app of the field operators. See [Introduction](../introduction.md). |
| **Offline** | Without a network. The app keeps your work and sends it when the network is back. See [Fill In Survey Forms Offline](../intervention/fill-in-forms-offline.md). |
| **Ongoing interventions** | The list of the interventions that you started. You open it from the **In progress** tab of the dashboard. See [View Your Ongoing Interventions](../main-actions/view-ongoing-interventions.md). |
| **Past days** | The days before today that the calendar can display, up to the limit that your administrator sets. See [See Your Unavailabilities in the Agenda](../menu/unavailabilities/see-unavailabilities-in-the-agenda.md). |
| **Photo** | A picture that you add to an intervention or to a site. See [Add Photos and Remarks](../intervention/photos-and-remarks.md) and [Add Photos to a Site](../customer-directory/add-photos-to-a-site.md). |
| **Position** | Your current location, which you can send to your team. See [Send Your Position](../menu/coworkers/send-your-position.md). |
| **Price calculation** | The calculation of the price of each item and of the total, with the tax. It starts when you tap the calculator button. See [Calculate the Price of the Items](../intervention/calculate-item-prices.md). Administrators: see [Price Calculation Setup](../configuration/price-calculation-setup.md). |
| **Privacy mode** | A switch that stops the sharing of your position and hides the positions of your coworkers. See [Privacy Mode](../menu/coworkers/privacy-mode.md). |
| **Quick actions** | The panel that opens when you press an intervention for a long time: call the contact, get directions, open the site or accept the intervention. See [Quick Actions on an Intervention](../main-actions/long-press-an-intervention.md). |
| **Remarks** | The text that you write about an intervention. Your administrator can hide the **Remarks** shortcut. See [Add Photos and Remarks](../intervention/photos-and-remarks.md#write-remarks). Administrators: see [Remarks Tab Setup](../configuration/remarks-tab-setup.md). |
| **Remove an item** | To swipe an item to remove it from the intervention. See [Remove an Item](../intervention/remove-an-item.md). |
| **Report** | The form that collects the information that your company needs about an intervention. A field with an asterisk (*) is mandatory. See [Fill in the Report](../intervention/report.md). |
| **Request a slot** | To ask the system to find the best slot for a new intervention. See [Request a Slot](../intervention/create-an-intervention/request-a-slot.md). |
| **Required photos** | The minimum number of photos that your company requires before you can finish an intervention. See [Take the Required Photos](../intervention/required-photos.md). Administrators: see [Required Photos Setup](../configuration/required-photos-setup.md). |
| **Reschedule** | To move an intervention to another date and time. See [Reschedule an Intervention](../intervention/reschedule-an-intervention.md). |
| **Rest** | A period of your agenda when you do not work. See [Calendar](../main-actions/calendar.md#day-agenda). |
| **Saved day** | The day that the calendar shows again when you come back from an intervention. See [Agenda Position and Saved Day](../main-actions/calendar-agenda-position.md). |
| **Search around** | The search for the sites around a position. Your administrator sets its limits. See [Search Around Settings](../configuration/search-around-settings.md). |
| **Secure signature** | An electronic signature. The signatory proves their identity with a code received by SMS, then signs. See [Sign Securely](../intervention/sign-an-intervention/sign-securely.md) and [Fill In the Required Fields for Electronic Signature](../intervention/sign-an-intervention/required-fields-for-electronic-signature.md). |
| **Serial number** | The code that identifies an item for one intervention. See [Scan or Enter a Serial Number](../intervention/scan-a-serial-number.md). Administrators: see [Serial Number Setup](../configuration/serial-number-setup.md). |
| **Settings** | The page where you clear the cache, read the conditions of use, send your logs and set your display preferences. See [Settings](../main-actions/settings.md). |
| **Sign by hand** | To have the report signed by hand on the screen, by the customer and by the technician. See [Sign by Hand](../intervention/sign-an-intervention/sign-by-hand.md). |
| **Signature** | The proof that the customer accepted the intervention. You sign by hand or securely. See [Sign an Intervention](../intervention/sign-an-intervention/README.md). Administrators: see [Signature Settings](../configuration/signature-settings.md). |
| **Site** | A location of a customer. See [Customer Directory](../customer-directory/README.md). |
| **Site details** | The details of a customer site, which you read before you act on it. See [View a Site](../customer-directory/view-a-site.md). |
| **Site document** | A file, an image or another document that is linked to a site. See [Add Documents to a Site](../customer-directory/add-documents-to-a-site.md). |
| **Site photo** | A photo or an image that illustrates a site. See [Add Photos to a Site](../customer-directory/add-photos-to-a-site.md). |
| **Sites list** | The list of the customer sites, where you find the site that you need. See [Browse the Sites List](../customer-directory/browse-the-sites-list.md). |
| **Survey report** | A report made of a form with several questions. See [Fill In Survey Forms Offline](../intervention/fill-in-forms-offline.md). |
| **Synchronization** | The exchange of data between the app and NFS. See [Refresh Your Data](../main-actions/refresh-your-data.md). |
| **Task** | A step that you complete during an intervention, before you accept it, before you start it or during it. See [Scan a Task Code](../intervention/scan-a-task-code.md). Administrators: see [Scan Task Setup](../configuration/scan-task-setup.md). |
| **Typical week** | The hours that you usually work on each day of the week. See [Set Your Typical Week](../menu/working-hours/typical-week.md). |
| **Unavailability** | A period when you are not available, for example a leave or a meeting. See [Unavailabilities](../menu/unavailabilities/README.md). Administrators: see [Unavailability Days Setup](../configuration/unavailability-days-setup.md). |
| **Waiting** | The status of a new intervention that is waiting for your answer. See [Intervention](../intervention/README.md#intervention-statuses). |
| **Working day** | The working hours of one day. You can add them or delete them. See [Add a Working Day](../menu/working-hours/add-a-working-day.md) and [Delete a Working Day](../menu/working-hours/delete-a-working-day.md). |
| **Working days** | Your working hours for the next 15 days. See [View Your Working Days](../menu/working-hours/view-your-working-days.md). |
| **Working hours** | The days and the hours when you are available. See [Working Hours](../menu/working-hours/README.md). |
