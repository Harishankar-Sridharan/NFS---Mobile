# Item and Price Settings

## Overview

These topics describe how to set up the items of an intervention: the products and the price calculation, the serial numbers, and the extra fields that technicians can see and edit.

## Topics

| Topic | Description |
| ----- | ----------- |
| [Price Calculation Setup](price-calculation-setup.md) | Set the products and prices used by the Items page of an intervention. |
| [Mandatory Serial Number Setup](mandatory-serial-number-setup.md) | Make the serial number of selected items mandatory, with a logical field on the product or with the access type of the filler. |
| [Scan Code Rules Setup](scan-code-rules-setup.md) | Limit the codes that the app accepts for the serial number of an item, with a regular expression. |
| [Serial Number Setup](serial-number-setup.md) | Choose where NFS stores the serial number scanned in NFS Mobile. |
| [Extra Item Fields Setup](extra-item-fields-setup.md) | Add extra fields to the items of an intervention, so that technicians can see and edit more information. |
