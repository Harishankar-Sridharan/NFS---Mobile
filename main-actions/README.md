# Main Actions

Use the main pages of NFS Mobile to manage your day in the field.

## Overview

Once you are logged in, the main pages of the app are available from the dashboard and from the navigation bar at the bottom of the screen.

This section covers:

| Topic | Description |
| ----- | ----------- |
| [Dashboard](main-actions.md) | See your day at a glance, search for an intervention and list the interventions in progress. |
| [Settings](settings.md) | Clear the cache, read the conditions of use, send your logs and set your display preferences. |
