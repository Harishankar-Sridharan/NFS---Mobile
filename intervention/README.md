# Intervention

Carry out an intervention from start to finish with NFS Mobile.

## Overview

An intervention is a visit planned for you at a customer site. In NFS Mobile, you start the intervention, fill in the report, add photos and remarks, then finish the intervention. Each step updates the intervention status, so your planner can follow your work.

This section covers:

| Topic | Description |
| ----- | ----------- |
| [Start an Intervention](start-an-intervention.md) | Open an accepted intervention, check its details and start it. |
| [Fill in the Report](report.md) | Fill in the report of the intervention. |
| [Add Photos and Remarks](photos-and-remarks.md) | Add photos and remarks to the intervention. |
| [Finish an Intervention](finish-an-intervention.md) | Finish the intervention and send your data. |
| [Cancel an Intervention](cancel-an-intervention.md) | Cancel an intervention in progress and return it to the accepted state. |
| [Abandon an Intervention](abandon-an-intervention.md) | Abandon an accepted intervention that you cannot carry out. |

## Intervention statuses

The status of the intervention is displayed on the **Intervention** page.

| Status | Description |
| ------ | ----------- |
| **Waiting** | The intervention is planned and waiting for your answer. See [Accept an intervention](../main-actions/calendar.md#accept-an-intervention). |
| **Accepted** | You have accepted the intervention. It is ready to start. |
| **In progress** | You have started the intervention. A timer shows its elapsed time. |
| **Completed** | You have finished the intervention. |
| **Abandoned** | You have abandoned the intervention. See [Abandon an Intervention](abandon-an-intervention.md). |

## Before you begin

* You are logged in. See [Login](../app-launch/app-launch.md).
* The intervention is in your agenda. See [Calendar](../main-actions/calendar.md).
