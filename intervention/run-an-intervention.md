# Run an Intervention

## Overview

These topics follow the life of an intervention in the app. You start it, complete its tasks, and finish it. If you cannot carry it out, you cancel it or abandon it, and an abandoned intervention can be started again.

## Topics

| Topic | Description |
| ----- | ----------- |
| [Start an Intervention](start-an-intervention.md) | Open an accepted intervention, check its details and start it. |
| [Keep the Task Comment When You Scan by Hand](task-comment-and-manual-scan.md) | Create a task in the app, and give the reason when you complete a scan task by hand, without losing the comment of the task. |
| [Edit, Reset or Delete a Task](edit-reset-or-delete-a-task.md) | Write or change the comment of a task, mark it as completed, reset it, or delete it from the Tasks page. |
| [Scan a Task Code](scan-a-task-code.md) | Complete a task by scanning its code, including a task whose code is recorded when you scan it. |
| [Finish an Intervention](finish-an-intervention.md) | Finish the intervention and send your data to NFS. |
| [Cancel an Intervention](cancel-an-intervention.md) | Cancel an intervention that you have started and return it to the accepted state. |
| [Abandon an Intervention](abandon-an-intervention.md) | Abandon an intervention that you cannot carry out. |
| [Restart an Abandoned Intervention](restart-an-abandoned-intervention.md) | Start again an intervention that was abandoned. |
| [Customized Appointment Button Labels](customized-button-labels.md) | Read the buttons of an intervention with the labels that your company chose. |
