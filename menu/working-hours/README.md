# Working Hours

Define the days and hours when you are available for interventions.

## Overview

The working hours tell NFS when you work. Planners use them to plan interventions for you. A working day has a morning period and an evening period, for example **07:30 - 10:00** and **15:00 - 18:00**.

This section covers:

| Topic | Description |
| ----- | ----------- |
| [View Your Working Days](view-your-working-days.md) | See your working hours for the next 15 days. |
| [Add a Working Day](add-a-working-day.md) | Define the hours of a day. |
| [Delete a Working Day](delete-a-working-day.md) | Remove the working hours of a day. |
| [Set Your Typical Week](typical-week.md) | Define the hours you usually work each day of the week. |

## Open the Working Hours page

1. In the navigation bar at the bottom of the screen, tap the **Menu** icon.
2. In the menu, tap **Working Hours**.
3. The **My working days** page opens.

To return to the menu, tap the back arrow at the top left.
